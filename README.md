# Project Singularity
standalone admin panel for FiveM servers, replaces txAdmin, works with any framework.

## Install on Linux
```bash
bash <(curl -s https://raw.githubusercontent.com/Sp3arHead/Project-Singularity-Dist/main/setup.sh)
```

## Install on Windows
```powershell
irm https://raw.githubusercontent.com/Sp3arHead/Project-Singularity-Dist/main/setup.ps1 | iex
```

## Requirements
Debian 11 or 12, Ubuntu 22.04 or 24.04, Windows Server 2019 or 2022, Windows 10 or 11. MariaDB and Apache are installed by the script if missing.

## Ports
panel 40120, game server 30120.

## What this repository contains
installer scripts and release downloads only. The source code is not public.
